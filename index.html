01

Набор данных

Student Performance, курс математики (student-mat.csv): 395 записей, 33 поля в исходном CSV. Данные двух португальских школ; автор — Paulo Cortez, UCI Machine Learning Repository. Лицензия CC BY 4.0.

02

Как считаем

G1, G2, G3 — оценки 1-го, 2-го периода и итоговая (0–20). Для визуализации введены группы: 0–9, 10–13, 14–20. studytime: <2, 2–5, 5–10, >10 часов в неделю. Среднее и доли рассчитываются по отфильтрованным строкам.

03

Ограничения интерпретации

Время на учёбу указано как категория, не точное число часов. Разделение на группы оценок выбрано для анализа. Корреляции не доказывают причинно-следственную связь. Две школы и один предмет не представляют всю совокупность школьников.

04

Доступность данных

Сайт пытается загрузить полный оригинал CSV. При недоступности источника доступен локальный проверенный фрагмент; режим работы явно обозначен выше.
